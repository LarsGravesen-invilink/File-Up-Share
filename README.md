# FileUpShare

Веб-панель управления раздачами и загрузками файлов на вашем Linux сервере.

## КОРОТКО О ВОЗМОЖНОСТЯХ:

- Раздача и приём файлов по HTTP/HTTPS с настраиваемыми индивидуальными страницами
- Приём файлов по HTTP/HTTPS от пользователей
- Видео, аудио, изображения и другие файлы
- Telegram бот с уведомлениями и мониторингом и возможностью управления.
- Защита паролем, поддержка шифрование, режим невидимки, установка временных лимитов
- Адаптация веб-страниц под смартфоны, планшеты, ПК


[Инструкция по управлению](instruction.md)


## УСТАНОВКА:

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/LarsGravesen-invilink/File-Up-Share/main/install.sh)
```



## ОБНОВЛЕНИЕ:

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/LarsGravesen-invilink/File-Up-Share/main/update.sh)
```
## Или короткая команда на сервере:

```bash
update-fileupshare
```



## УДАЛЕНИЕ:

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/LarsGravesen-invilink/File-Up-Share/main/uninstall.sh)
```
## Или короткая команда на сервере:

```bash
uninstall-fileupshare
```
