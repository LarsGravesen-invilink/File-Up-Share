# FileUpShare

Панель управления раздачами и загрузками файлов на вашем Linux VPS.

## Возможности

- Раздача файлов с настраиваемыми страницами
- Приём файлов от пользователей
- Поддержка в режиме просмотра видео, аудио, изображений
- Telegram бот с уведомлениями и мониторингом
- Защита паролем, шифрование, режим невидимки
- Адаптация под смартфоны, планшеты, ПК

## Установка

[Инструкция по управлению](instruction.md)

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/LarsGravesen-invilink/File-Up-Share/main/install.sh)
```

## Обновление

```bash
update-fileupshare
```

## Удаление

```bash
uninstall-fileupshare
```
