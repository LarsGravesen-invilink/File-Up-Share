# FileUpShare — Инструкция

## Первый запуск

Установка запускается командой:

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/LarsGravesen-invilink/File-Up-Share/main/install.sh)
```

После установки откройте панель по адресу вашего домена или IP. При первом входе создайте логин и пароль. Эти данные используются для доступа в панель управления.

## Информация (Дашборд)

Главная страница после входа. Показывает количество раздач, загрузок, принятых файлов и занятое место. Информация о сервере: IP, имя, время, порты, загрузка CPU и RAM. Кнопки: логи панели, проверка системы, перезапуск сервиса.

## Создать раздачу

Добавьте один или несколько файлов. Можно добавить обложку в формате 4:3 с автокропом. Выберите режим: «Загрузка» показывает кнопки скачать рядом с каждым файлом, «Только просмотр» скрывает кнопки. В режиме просмотра можно отдельно разрешить скачивание. Настройте время жизни страницы, скрытие расширений, пароль доступа. Заголовок и комментарий отображаются на странице. Если в настройках безопасности включён глобальный пароль, индивидуальный пароль не предлагается. Кнопка «Предпросмотр» открывает страницу без публикации. «Опубликовать» создаёт страницу и показывает ссылку для копирования.

## Создать загрузку

Создаёт страницу для приёма файлов от пользователей. Укажите заголовок, комментарий, время жизни, лимит файлов за раз и количество загрузок. Можно разрешить комментарий от загрузчика (до 100 символов). Пароль доступа настраивается индивидуально или глобально.

## Мои раздачи

Список созданных раздач. Для каждой: копирование ссылки, отправка через системный диалог «Поделиться» с текстом «С Вами поделились файлом», продление времени жизни, предпросмотр, удаление. Ссылки зашифрованы в base64.

## Мои загрузки

Аналогичный список страниц загрузки. Информация о количестве использованных загрузок и лимитах. Поделиться с текстом «Вас просят загрузить файл».

## Принятые файлы

Файлы, загруженные пользователями. Каждый файл: имя, размер, тип, время получения, источник (страница загрузки), комментарий пользователя. Кнопки скачать и удалить.

## Внешний вид страниц

Выбор темы для публичных страниц раздач и загрузок. 11 тем: 6 тёмных и 5 светлых. Каждая тема фиксирует цвета текста, фона, кнопок для читаемости. Выбор подтверждается модальным окном и применяется ко всем страницам. Можно скрыть таймер времени жизни. Рекламный блок внизу страниц: включение/выключение, текст с кликабельными ссылками. По умолчанию показывается ссылка на проект.

## Настройка панели

Брендинг: изменение названия сервиса и логотипа. Логотип загружается с устройства, автосжимается до 256px, поддерживает прозрачность. Тема панели: тёмная или светлая с плавной анимацией смены. Хранилище: пути раздач и загрузок с нередактируемым префиксом, квота с минимумом 100 МБ. Масштаб интерфейса: 3 уровня пропорционального увеличения всех элементов. Масштаб верхней зоны: отдельное увеличение шапки, логотипа и кнопки меню. Дата и время: автоматическая синхронизация или ручной ввод с выбором часового пояса.

## Безопасность

Смена логина и пароля с подтверждением. После изменения сессия завершается. Шифрование файлов на сервере. Глобальный пароль для всех раздач и отдельно для всех загрузок. Режим невидимки: бот скрывает панель по команде /close и восстанавливает по /open. Аварийное восстановление командой unlock-my-panel на сервере.

## Telegram bot

Включение/выключение бота. Статус: Запущен, Остановлен, Не настроен. Подключение: токен бота, выбор куда отправлять (бот-чат, канал, личные сообщения). Мониторинг новых файлов с настраиваемым интервалом. Уведомления: новая раздача, новая загрузка, принятый файл, служебные (обновления, место на диске). Каждое уведомление с inline-кнопками: копирование ссылки, получение файла, очистка. Время покоя: интервал без уведомлений. Ежедневная сводка: статистика за сутки в настраиваемое время.

## Генерируемые страницы

Анимированный фон, бегущая строка с названием сервиса, логотип. Изображения открываются на полный экран по нажатию. Видео с каруселью и полноэкранным режимом с автоповоротом. Аудио со списком плееров, запуск одного останавливает другие. Множественные файлы отображаются компактным списком по 5 штук. Защита от копирования текста и изображений. Пароль доступа: поле ввода по центру с кнопкой «Получить доступ». На телефоне кнопка «назад» закрывает полноэкранный просмотр.

## Команды сервера

| Команда | Действие |
|---------|----------|
| `update-fileupshare` | Обновление из репозитория |
| `uninstall-fileupshare` | Полное удаление |
| `unlock-my-panel` | Аварийная разблокировка |
| `systemctl status fileupshare` | Статус сервиса |
| `systemctl restart fileupshare` | Перезапуск |

## Хранение файлов

Раздачи: `/var/lib/fileupshare/shares/`
Загрузки: `/var/lib/fileupshare/received/`
Пути можно изменить в настройках панели. При изменении файлы переносятся автоматически, ссылки не меняются.
